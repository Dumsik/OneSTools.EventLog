<issue>
Нужен мониторинг успешного экспорта данных журнала регистрации в zabbix. 
</issue>

<Требования>
    1. Мониторинг реализуем только в режиме запуска Manager. OneSTools.EventLog.Exporter.Manager отвечает за отправку данных мониторинга в zabbix и за отправку Discovery.
    2. Все настройки мониторинга задаются в appsettings.json 
    3.должен быть параметр включающий отправку данных в zabbix , если он выключен (по умолчанию) функционал мониторинга выключен ничего не отправляется. Это же справедливо для отправки LLD Discovery
    4. Параметры "Сервер zabbix" и "host zabbix для элементов данных" задаются в appsettings.json они общие для отправки статуса и discovery.    
</Требования>

<Реализация отправки статуса>
    1.факт выгрузки данных будет отправляться в zabbix в элемент данных типа trapper. В случае успешной выгрузки отправляется OK, в случае ошибок FAIL. 
    2.Отправка данных в zabbix просходить после выгрузки порции данных считанных для загрузки, не после каждой строки. Если данных для выгрузки нет, то отправляется OK. 
    3.Данные отправляются в URL формата https://%Сервер zabbix%/zabbix_sender/index.php?server=%host zabbix для элементов данных%&key=%key%&value=%value%". методом POST
    4. key всегда равен ExportStatus[%1]. где %1 это имя базы для которой выгружаются записи журнала регистрации
    5. value - статус выгрузки.
</Реализация отправки статуса>

<Реализация отправки LLD discovery>
    1.в zabbix отправляются данные LLD discovery по базам для которых выполняется выгрузка журнала регистрации.
    2. discovery отправляется раз в сутки в URL формата https://%Сервер zabbix%/zabbix_sender/index.php. методом POST.
    3. Параметры передаются в формате "application/x-www-form-urlencoded; charset=utf-8".
    4. Параметры запроса: server=%host zabbix для элементов данных%&key=%key%&value=%value%"
    5. key всегда равен EventLog.ExportStatus.Discovery
    6. value это массив с именами всех баз для которых выгружаются данные. Имя ключа #IBNAME. Json сформирован в формате zabbix lld discovery
</Реализация отправки LLD discovery>
